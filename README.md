## Featured Projects

### 🚆 RailGuard — Train Seat Reservation System
**First Semester | HTML, CSS, JavaScript, Python**

RailGuard is a railway reservation project comprising a website built with HTML, CSS, and JavaScript and a console-based train seat reservation application built with Python. The project focuses on organizing the seat reservation process and presenting railway services through a dedicated web interface.

Building RailGuard helped me develop foundational skills in web design, programming logic, and translating a practical problem into a software solution.

### 🛠️ Hunarmand — Connecting Customers with Skilled Workers
**Second Semester | C#, Object-Oriented Programming, ASP.NET Core Razor Pages**

Hunarmand is a service hiring website that connects customers with plumbers, masons, and electricians for their personal and household work. It brings different skilled trades into one platform, helping customers find the type of professional they need.

Built with C# and Razor Pages, the project allowed me to apply object-oriented programming concepts to structure application logic and develop a web application around a real-world service need.
